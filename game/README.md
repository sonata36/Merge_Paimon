# 合成大派蒙（课程演示版）

当前版本采用电脑横版页面：中左为棋盘，右侧集中显示分数、下一角色、静音、预备位与八级图鉴。建议浏览器窗口至少 1100 像素宽；窄窗口会提示扩大窗口。轻推技能每局限用两次，选中已落稳的 1～4 级角色后可向左或向右施加一次小幅推力。开始提示、失败与重开界面、短音效、背景音乐和静音开关均保留。八级角色图片与复合碰撞体共用逐级递增的尺寸配置；待投放角色下方的短虚线标示投放横向位置，碰到已有角色后实际停留位置可能改变。图鉴只显示各级图片和等级。玩家页面已移除碰撞体显示按钮。项目负责人的个人、非商业课程演示使用《原神》曲目 **A Day in Mondstadt**；文件已随仓库提交，来源与范围见 `docs/音乐素材清单.md`。

## 桌面版视觉

背景使用 `assets/backgrounds/mondstadt-morning.png`，为 2026-10-28 使用图像生成工具制作的原创晴天风车城景；来源说明见 `assets/backgrounds/README.md`。暖金、草绿和星形边饰由页面样式绘制；棋盘边框与投放虚线同步换色，角色仍使用既有八级 PNG。背景图约 2.5 MB，首次打开可能比纯色背景多一次图片加载。

## 直接打开游戏

双击 `game/index.html`，或从文件卡片选择在浏览器打开。它会自动加载 `game/offline/game.js`、`game/offline/game.css`、八张角色 PNG 和 `game/assets/audio/a-day-in-mondstadt.mp3`，无需先启动开发服务器。点击开始后会尝试播放音乐；音频加载或播放受阻时游戏仍可运行。请保留 `offline/`、`assets/` 与 `index.html` 在同一项目目录内。文件模式使用 Canvas 渲染和本地图片加载，以避开浏览器对 `file:` 图片 XHR / WebGL 上传的限制。修改源代码后执行 `npm run build` 更新本地文件版；只运行 `npm run dev` 不会更新该版本。

文件版不显示 `?test=1` 开发验收控件。需要这些控件时，按下文启动 Vite 开发服务，再打开服务地址。

## 环境要求

- Node.js 22.12 或更新版本（本项目使用 Vite 7）
- npm（随 Node.js 安装）
- 本地桌面浏览器

## 安装与启动

在终端进入本文件所在的 `game/` 目录，然后执行：

```powershell
npm install
npm run dev
```

如果当前环境的 npm 默认缓存目录没有写入权限，可改用项目内缓存安装：`npm install --cache .npm-cache`。

终端会显示本地访问地址，通常为 `http://localhost:5173/`。用浏览器打开该地址即可查看页面。按 `Ctrl+C` 停止本地服务。

## 构建与预览

```powershell
npm run build
npm test
npm run benchmark:physics
npm run preview
```

`npm run build` 先检查 TypeScript，再生成服务部署用的 `dist/`（包含八张 PNG 和 MP3）及直接打开 HTML 所需的 `offline/` 脚本与样式。`npm test` 检查八张 PNG 的格式、尺寸和区别，八级复合体的落地、堆叠与旋转，以及合成、失败和重开规则。`npm run benchmark:physics` 在 Node 中模拟 50 枚复合体运动 1800 帧，只测 Matter 计算，不包含浏览器绘制。`npm run preview` 会启动本地构建结果预览服务；预览地址以终端输出为准。

## 操作规则

- 页面载入后先点击“开始游戏”，再操作棋盘；BGM 只在点击开始后播放并循环，失败时暂停、重开时恢复。若浏览器不提供音频设备或阻止播放，游戏仍可运行。
- 鼠标移动时，顶部半透明角色预览横向跟随；在画布内按下并松开鼠标投放。
- 点击右侧“暂存 / 交换”可将当前 1～3 级待投放角色放入预备位；预备位已有角色时与当前角色交换。每次实际投放前只能操作一次，投放后恢复可用。开始前、失败后不可操作；重开时清空预备位。首次暂存会启用原先的下一角色并重新抽取下一角色。
- 点击“选择轻推目标”进入轻推模式，点击棋盘中已落稳的 1～4 级角色，再点左推或右推。每局 2 次；选目标时不会投放新角色，点击“取消选择”或再次点击“取消轻推”可退出。轻推本身不加分，由此产生的同级碰撞仍按正常合成计分；失败后不可用，重开恢复次数。
- 当前页面按桌面鼠标操作排版；本轮未改变底层触屏输入代码。
- 每次成功投放后有 **400 毫秒冷却**；冷却期间的输入被忽略，不排队补投。
- 预览位置和出生点按当前等级碰撞体的水平半宽夹在棋盘两侧墙壁内，额外留 2 像素间隙。画布内但棋盘左右外侧的点击/触摸会夹到最近的合法位置；画布外松开不会投放。
- 正常模式的待投放等级为 1～3 级，各占 `1/3`；下一枚等级显示在棋盘上方。一次同级合成生成目标等级 `L`，加 `2^L` 分。例如 1+1→2 加 4 分，7+7→8 加 256 分。异级和 8+8 不合成。
- 红色水平线为警戒线，以角色**物理碰撞体上边界**越过线来判定。新投放角色从释放起先享有 **2 秒宽限**；宽限结束后，任一角色持续越线 **3 秒**才结束。中途完全回到线下，该角色的 3 秒计时清零；合成产生的新角色没有新投放宽限。
- 结束时物理世界暂停、分数保留在结束界面，无法继续投放。点击“重新开始”会清空上一局角色、分数、待合成事件和越线计时，恢复随机待投放队列与物理运行。
- 右侧栏显示当前分数、下一角色图片和八级图鉴；每局首次成功投放显示一次“投放”浮字，此后投放不重复提示；合成仍显示加分浮字。投放、合成和结束保留各自的程序合成短音。点击“静音”会同时关闭 BGM 和短音效，再点“开启声音”可恢复。

## 复合碰撞体

`src/config/LevelCatalog.ts` 为每级单独定义 `parts`。圆形与矩形零件的坐标、半径、宽高均以本级 `radius` 为单位；`radius` 是缩放基准，不表示轮廓是圆。当前 1～8 级 radius 依次为 **28/34/40/46/57/61/74/90**；第 5 级略放大，以拉开与第 4 级的视觉差距；6→7 与 7→8 的尺寸增幅均约 21%。八张 PNG 均为 512×512 RGBA，主体置于画布中央，游戏显示尺寸为本级 `radius × 2.1`；图片与物理子体一起缩放。Matter 的复合体质量中心可能偏离图片中心，场景据此调整贴图原点，让角色转动时画面和物理子体仍对齐。发梢、围巾末端和凹陷只用少量凸形子体近似。

| 等级 | 图片姿势与复合轮廓 | 零件数 |
| --- | --- | ---: |
| 1 | 蜷缩睡觉；纵向紧凑三圆 | 3 |
| 2 | 横向滑翔；头部、身体和两侧手臂 | 4 |
| 3 | 站立指向上方；头部和竖直身体 | 4 |
| 4 | 斜向翻滚；偏心头部、身体、手和脚 | 4 |
| 5 | 横向躺卧；长身体、头和伸出的手脚 | 5 |
| 6 | 蹲坐鼓脸；头、身体、双手和双脚 | 6 |
| 7 | 举手惊讶；头、竖直身体、双手和双脚 | 6 |
| 8 | 张开庆祝；头、身体、双手和双脚 | 6 |

所有零件组合成一个 Matter 刚体，旋转时一起绕物理重心转动；贴图原点按复合体实际重心偏移补偿。八级都已在浏览器调试视图核对，细小装饰与透明边缘不追求逐像素碰撞，以免增加接触点和堆叠抖动。

碰撞体显示按钮已从玩家页面和场景逻辑中移除。八级轮廓配置仍在 `src/config/LevelCatalog.ts`，结构与物理行为可通过 `npm test` 检查；开发期已保存的调试截图位于 `docs/第10轮_八级碰撞核对总览.png`。

## 本地验收模式

使用开发服务打开 `http://localhost:5173/?test=1`（端口以终端输出为准）。页面底部出现测试控件；选择 1～8 级并点击“设为待投放”，然后在棋盘投放。**同一等级每投放一次前都要再点一次按钮**，因为投放后待投放角色会回到正常的 1～3 级随机队列。“三枚 1 级同时接触”可稳定产生 4 分。“固定角色越线”会在警戒线上方放一枚静止、刚释放的 1 级角色；“移回线下”和“再次越线”用于检查计时清零。“50 枚压力测试”会清空棋盘并放入 50 枚第 1、2 级复合体，30 秒后显示浏览器平均帧率；测试期间暂不合成或判负，刷新页面退出。用 `?test=1&missing=4` 可模拟第 4 级缺图，页面会明确提示并显示程序数字占位图。测试控件只在开发服务且 URL 带 `?test=1` 时启用；普通页面和生产构建不显示这些控件。

## 本轮人工检查（桌面横版、预备位与轻推）

1. 在约 1366×768 的电脑窗口打开页面：中左应完整显示棋盘，右侧应显示分数、下一角色和策略区；图鉴后半部分可在右侧面板内滚动查看。
2. 点击开始，移动鼠标到棋盘左、中、右位置并投放，确认预览虚线与落点正常；分数和下一角色随原规则变化。
3. 缩短窗口高度后检查棋盘按高度保持 3:4 比例并缩放，右侧内容可独立滚动；按钮与文字不能被遮住。
4. 将窗口宽度缩到 1100 像素以下，确认出现“请扩大浏览器窗口”的提示；恢复宽窗口后可继续操作。
5. 完成一次合成并触发失败/重开，确认右侧分数与图鉴、开始和失败弹层均保持可见可用。
6. 开始游戏后点击“暂存 / 交换”，确认预备位显示等级与图片、待投放预览切换；投放前按钮应禁用，投放一枚后可再次交换。失败后按钮不可用，重开后预备位清空。
7. 投放一枚低等级角色并等其落稳；点击“选择轻推目标”并选中它，再点击左推或右推，确认次数减一且没有额外投放。点击取消按钮应退出轻推模式；未落稳或 5～8 级角色不能作为目标；用完两次后按钮禁用，重开恢复。

## 当前文件

- `src/main.ts`：创建 Phaser 游戏和 Matter 物理配置。
- `src/scenes/GameScene.ts`：加载角色 PNG、请求失败后重试一次、真正缺图时显示占位、绘制棋盘和创建 Matter 物理对象。
- `src/config/LevelCatalog.ts`：八级图片尺寸、复合碰撞配置及 1～3 级随机抽取。
- `assets/characters/lv1.png`～`lv8.png`：八张实际使用的透明角色图；构建时复制到 `dist/characters/`。
- `vite.config.ts`：开发/构建入口和角色图静态目录配置。
- `src/domain/CompoundBody.ts`：根据每级零件创建 Matter 复合刚体。
- `src/domain/DropController.ts`：指针预览、等级队列、边界夹取与冷却。
- `src/domain/Piece.ts`：活动角色的数据结构。
- `src/domain/MergeResolver.ts`：同级判定、接触锁定及待结算队列。
- `src/domain/GameSession.ts`：本局分数、结束状态及每枚角色的连续越线计时。
- `src/domain/SoundFeedback.ts`：原创程序合成音效、用户操作后解锁音频与静音控制。
- `src/domain/BackgroundMusic.ts`、`assets/audio/a-day-in-mondstadt.mp3`：本地 BGM 播放控制及实际曲目文件。
- `tests/rules.test.mjs`：可控输入的规则测试。
- `tests/compound.test.mjs`：真实 Matter 复合体、尺寸与落地模拟测试。
- `tests/assets.test.mjs`：八张 PNG 文件格式、画布与相互区别检查。
- `tests/physics-benchmark.mjs`：50 枚复合体的物理计算基准。
- `src/style.css`：页面排版与窄窗口适配。
- `index.html`：页面结构与画布容器。

角色原图与来源位于上级目录的 `docs/素材原图/`、`docs/素材清单.md`；BGM 来源、下载途径与用途位于 `docs/音乐素材清单.md`。投放、合成、失败短音仍由 Web Audio 实时合成。
