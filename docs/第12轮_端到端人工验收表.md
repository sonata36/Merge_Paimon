## 准备方式

1. 在 `game/` 目录执行 `npm install`（已安装依赖时可跳过），再执行 `npm run dev`。使用终端显示的端口打开普通页面，并把 `?test=1` 加到地址末尾打开开发验收页，例如 `http://localhost:5173/?test=1`。端口不一定是 5173。
2. 普通页面用于完整游玩和界面体验。开发验收页底部的“设为待投放”“三枚 1 级同时接触”“固定角色越线”“移回线下”“再次越线”“50 枚压力测试”等按钮，只用于制造可重复场景；它们不出现在普通页面和直接双击打开的本地文件版。
3. 每个需要空棋盘的用例先刷新页面、点击“开始游戏”。指定同一等级投放两次时，**每次投放前**都要重新选择等级并点击“设为待投放”；成功投放后队列会回到正常的 1～3 级随机规则。两次投放至少间隔 0.4 秒。
4. 建议备好计时器、可听声音的设备和一台真实触屏设备。浏览器的触屏模拟可以辅助定位问题，但不能代替真机触屏验收。
