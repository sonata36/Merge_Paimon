# 合成大派蒙 · Coding Agent 课程项目

本仓库记录通过自然语言与 Coding Agent 逐轮开发的本地单人网页游戏。玩家投放 1～3 级角色，同级碰撞后合成升级并计分；角色持续越过警戒线会结束本局。项目使用 TypeScript、Phaser 和 Matter.js，提供八级原创透明角色图与复合碰撞体。

## 运行

进入 `game/`，执行：

```powershell
npm install
npm run dev
```

终端会显示本地访问地址。也可先执行 `npm run build`，再直接打开 `game/index.html`；仓库已包含离线脚本。完整操作、测试和目录说明见 [游戏 README](game/README.md)。
